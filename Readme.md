libfpga
=======

The `libfpga` fork for the [ULX3S and ULX4M Hazard Doom Project](https://github.com/ulx3s/Hazard3-Doom).

This is a collection of components from Luke Wren's [libfpga](https://github.com/Wren6991/libfpga) accumulated from FPGA projects (mainly RISCBoy).

They're written in synthesisable Verilog 2005.

This `libfpga` is included as a submodule in the [ulx3s/Hazard3/example_soc](https://github.com/ulx3s/Hazard3/tree/736a74459b3f740c47803f20a62d820fcacbe5c3/example_soc)  
(currently at commit [9d50e12e01](https://github.com/Wren6991/libfpga/tree/9d50e12e01efb59c45f4f71ff5d650a7fb7c6acc)).

Additional commits are added here to support low-resource targets such as the ULX3S-12F.

The default branch for ULX targets is the [ulx-doom](https://github.com/ulx3s/Hazard3/tree/ulx-doom) branch,
the same as for the [ULX3S Hazard3 fork](https://github.com/ulx3s/Hazard3/tree/ulx-doom)
